# أغراض البيت

## الرفع على Render
1. ارفع هالمجلد كله على مستودع GitHub جديد (private أحسن).
2. على render.com: New + ← Blueprint ← اختار المستودع.
3. بيطلب منك FAMILY_PASSWORD: اكتب كلمة سر للعيلة.
4. اضغط Apply وانتظر. بعدها بيطلع لك رابط مثل https://bait-app.onrender.com
5. ابعت الرابط وكلمة السر للعيلة.

## على التليفونات
- أندرويد (Chrome): افتح الرابط ← ⋮ ← "تثبيت التطبيق" ← فعّل الإشعارات.
- آيفون (Safari، iOS 16.4+): مشاركة ← "إضافة إلى الشاشة الرئيسية" ← افتحه من الأيقونة ← فعّل الإشعارات.
